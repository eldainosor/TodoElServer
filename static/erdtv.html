El Rock de Tu Vida - Revival de TodoElServer

Introducción

Este es un servidor que busca revivir los servicios de El Rock de Tu Vida. Esto es una implementación online de un proyecto para hacerlo offline que se encuentra en este repo de GitHub.

No conocés el juego? Hay gameplay del juego archivado en este canal de YouTube o podés ver la siguiente promo:


Estado actual del TodoElServer

El proyecto de TodoElServer soporta iniciar sesión en el juego y poder usar las 28 canciones que se encuentran en los 2 lanzamientos del juego (con la posibilidad de verificar archivos locales, si es que está instalado). No hace falta registrarse.

Esto es una implementación inicial, aunque quien sabe si en el futuro se pueda implementar:

  • Servicio de Ads (solo por cuestiones de preservación)
  • Sistema de puntajes online con registro y guardado
  • Vista de catálogo online

Planes futuros del proyecto

Actualmente se hicieron pruebas offline de este servicio pero requiere ingenieria inversa, parcheo del ejecutable y un server web. La idea de una implementación offline consiste de:

  • Modificación del ejecutable para la comunicación exclusiva con el servidor ficticio para poder usar todas las funciones del juego
  • Armado de un server interno (o con otro ejecutable) sin depender de Python y que funcione en Win7 para arriba
  • Guardado 100% local
  • Sistema para generar customs de Rock Band a Mozart (Proyecto Arbys2Mostaza???)
  • Conservado de DLCs restantes

Los DLCs perdidos

Luego de una investigación larga hecha por TodoElRock, descubrimos que hay más de 30 canciones que no se pueden obtener de ninguna manera. No hay archivos, ni registro, ni nada. Se puede considerar lost media?

¿Porqué esto existe?

Porque es importante la preservación de Software. Este proyecto comenzó con Envido32 queriendo ver si se podía "crackear" el juego y convertir las canciones a un formato de Guitar Hero/Rock Band, y terminó con ElDainosor implementando un servidor atado con alambre para hacer funcional el juego otra vez.

Todavía queda mucho por hacer y por preservar. Cuidemos nuestro software 🇦🇷
